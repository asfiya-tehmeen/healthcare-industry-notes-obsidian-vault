# Glossary (plain English)

**Active ingredient / API** – The chemical that actually does the work in a drug. (API here = Active Pharmaceutical Ingredient, not software API.)
**ADaM** – CDISC format for *analysis-ready* trial datasets. See [[04-Data-Standards/CDISC-SDTM-ADaM]].
**Adverse Event (AE)** – Any bad medical event during treatment, whether or not the drug caused it.
**ALCOA+** – Rules for trustworthy data: Attributable, Legible, Contemporaneous, Original, Accurate (+ Complete, Consistent, Enduring, Available).
**ANDA** – Application to approve a generic drug in the US.
**Audit trail** – Tamper-proof log of who changed what, when, why.
**Biologic** – Drug made from living cells (e.g. insulin, antibodies). Biosimilar = "generic" of a biologic.
**BLA** – Biologics License Application.
**CAPA** – Corrective And Preventive Action: fix a problem and stop it recurring.
**CDISC** – Standards body for clinical trial data formats.
**CRF / eCRF** – (Electronic) Case Report Form: the form capturing each patient's trial data.
**CRO** – Contract Research Organization; company hired to run trials (IQVIA, Parexel, ICON).
**CDMO / CMO** – Contract manufacturer.
**CSV** – Computer System Validation (not comma-separated values!). See [[03-Regulatory-Compliance/Computer-System-Validation]].
**CTD / eCTD** – Common Technical Document: the standard dossier format for submissions.
**DSUR / PSUR / PBRER** – Periodic safety reports.
**EDC** – Electronic Data Capture: software where sites enter trial data (Medidata Rave, Veeva EDC).
**EHR / EMR** – Electronic Health/Medical Record (Epic, Cerner/Oracle Health).
**EMA** – European Medicines Agency.
**FDA** – US Food and Drug Administration.
**FHIR** – Modern API standard for health data exchange.
**Formulary** – List of drugs an insurer covers.
**GCP / GLP / GMP / GDP / GVP** – Good Clinical / Laboratory / Manufacturing / Distribution / Pharmacovigilance Practice. Together "GxP".
**GAMP 5** – Industry guide for validating computerized systems.
**Generic** – Copy of an off-patent drug.
**HCP / HCO** – Healthcare professional / organization (doctor / hospital).
**HIPAA** – US law protecting patient health information.
**ICH** – International Council for Harmonisation; writes guidelines (E6 GCP, Q10, etc.).
**ICSR** – Individual Case Safety Report (one adverse event report).
**IND** – Investigational New Drug application; permission to start human trials in US.
**IRB / EC** – Ethics committee that approves trials.
**MedDRA** – Dictionary for coding adverse events.
**NDA** – New Drug Application (US marketing approval request).
**NDC** – National Drug Code; ID for a US drug product/package.
**OMOP** – Common data model for observational health data.
**PBM** – Pharmacy Benefit Manager (Express Scripts, CVS Caremark, Optum Rx); middlemen negotiating drug prices.
**Pharmacovigilance (PV)** – Monitoring drug safety after launch.
**Phase I/II/III/IV** – Stages of clinical trials. See [[02-Drug-Development/Clinical-Trials-Explained]].
**PHI / PII** – Protected Health Information / Personally Identifiable Information.
**RWD / RWE** – Real-World Data / Evidence (from claims, EHR, registries).
**SAE** – Serious Adverse Event.
**SAP** – Statistical Analysis Plan.
**SDTM** – CDISC format for *tabulated raw* trial data.
**SOP** – Standard Operating Procedure.
**TMF / eTMF** – (Electronic) Trial Master File: the trial's document archive.
**URS / FS / IQ / OQ / PQ** – Validation documents/tests: User Requirements, Functional Spec, Installation/Operational/Performance Qualification.
**Veeva** – Dominant cloud software vendor in life sciences (CRM, Vault QMS, RIM, etc.).
**WHO-DD** – WHO Drug Dictionary for coding medications.
