# Certifications & Communities

## Worth it for data + compliance
| Cert | Why | Cost level |
|---|---|---|
| **GCP training (ICH-GCP E6)** | needed for any clinical role; TransCelerate-recognized | free–low |
| **HIPAA training** | privacy basics | low |
| **CITI GCP/HSR** | research ethics | employer |
| **ISPE GAMP training / CSV certificate** | validation credibility | medium |
| **CDISC SDTM/ADaM certification (CDISC Academy)** | standards programmer | medium |
| **SAS Clinical Trials Programmer** | statistical programming | medium |
| **ACRP-CP / SOCRA CCRP** | clinical research | medium |
| **ASQ CQA / CQE** | quality | medium |
| **CDMP / DAMA** | data management | medium |
| **Cloud: AWS/Azure/GCP data cert, Snowflake SnowPro, Databricks DE Associate** | engineering | medium |
| **HL7 FHIR Proficiency** (HL7 International) | interoperability | medium |
| **CHDA / CPHIMS / AHIMA** | health data/IT | medium |
| **CISSP/ISO 27001 LA** | security | high |
| **PMP** | optional | high |

Priority order for you: GCP → HIPAA → cloud data cert → CDISC/FHIR → GAMP training.
