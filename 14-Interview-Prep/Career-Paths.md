# Career Paths in Pharma/Healthcare Data & Compliance

| Role | Day-to-day | Key skills | Entry difficulty |
|---|---|---|---|
| Clinical Data Engineer / Programmer | build pipelines from EDC/vendor data to SDTM; automate checks | SQL, Python, CDISC, cloud | Medium |
| Statistical Programmer (SAS/R) | SDTM/ADaM, TLFs | SAS/R, CDISC | Medium |
| Clinical Data Manager | cleaning, queries, DB lock | EDC, GCP, SQL | Easy–Med |
| Data Scientist (RWE/commercial) | modeling, cohort, forecasting | stats, Python/R, OMOP | Medium–Hard |
| Healthcare Data Engineer (payer/provider) | claims, FHIR, EHR ETL | SQL, Spark, FHIR | Medium |
| Pharmacovigilance Data Analyst | signal detection, safety DB | MedDRA, SQL | Easy–Med |
| CSV / Computer System Validation Analyst | validate GxP systems | GAMP, documentation | Easy–Med |
| Data Integrity / GxP Compliance Specialist | audits, audit trail review | Part 11, ALCOA, SOPs | Medium |
| QA / Quality Systems Analyst | deviations, CAPA, QMS | GMP, Veeva QMS | Easy–Med |
| Regulatory Operations (RIM/eCTD) | publishing submissions | eCTD, Veeva RIM | Easy–Med |
| Privacy/Data Governance Analyst | HIPAA/GDPR, catalogs | privacy law, Collibra | Medium |
| Commercial/Field analytics | targeting, dashboards | SQL, Tableau/Power BI | Easy–Med |
| Health informatics analyst (hospital) | Epic reporting | Clarity SQL, Epic certs | Medium |
| Pharma AI/automation engineer | LLM/RPA with validation | Python, MLOps, GxP | Medium–Hard |

## Suggested positioning (data + compliance)
"Data engineer who understands regulated environments" — rare and valuable. Target: **Clinical Data Engineer, GxP Data Engineer, Data Integrity Analyst, CSV/Data Governance Analyst** at pharma, CROs, GCCs, consulting (ZS, IQVIA, Deloitte, Tredence, Indegene).

## Resume bullets (examples to adapt after projects)
- "Built Airflow/dbt pipeline transforming synthetic EDC data into CDISC SDTM domains with 40+ automated validation checks and SHA-256 file integrity logging."
- "Designed Part 11–aligned audit trail schema; wrote SQL review reports flagging anomalous edits."
- "Mapped Synthea FHIR data to OMOP CDM and ran DQD (98% pass)."
